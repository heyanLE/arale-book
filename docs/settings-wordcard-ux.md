# 设置与词卡交互整理

核对日期：2026-09-28。实现分支 codex/settings-wordcard-ux。本页描述当前实现及待验收范围。

## 设置的信息架构

| 分类 | 内容 | 原则 |
|---|---|---|
| 通用 | 书库、词典、外观、LLM、翻译、OCR 默认引擎、OCR 扩展与仓库 | 两种阅读器都可能使用的能力集中管理 |
| 小说 | 字号、字体、行高、页边距、竖排 | 只影响 EPUB 阅读器 |
| 漫画 | 新书方向、页面适配、双页和配对偏移 | 只影响漫画阅读器 |

设置顶部固定“通用 / 小说 / 漫画”跳转按钮，正文按相同顺序排布。OCR 扩展与仓库紧跟 OCR 默认引擎。OCR 单选项只决定全局预选引擎；漫画阅读器中的引擎下拉框可为本书选择其他已安装引擎，并记住本书覆盖值。多个引擎可以同时可用。

## LLM 与翻译配置

新建使用独立草稿，未保存时不进入已保存列表，也没有“默认”单选项。LLM 新建只需名称和地址，保存后再填写模型、温度和 Key；翻译新建填写名称、提供商和可选地址，保存后再补充密钥。新建表单有自己的“保存新配置 / 取消”。密钥由单独按钮保存，输入框失焦不会触发写盘。

点击“默认”只修改已保存配置的默认 id，不会清除未保存的新建草稿。LLM 的配置列表与提示词一起提交，避免两个异步写盘调用相互覆盖。删除已保存配置时，配置数组和默认 id 在同一次更新中提交。

翻译服务始终提供固定 id tr_bing_default 的 Bing 网页翻译项，首次打开就是默认项；它无需 Key、不能删除或改成其他提供商，设置中以简短的内置项显示。用户可以新建其他翻译配置并改设默认。词卡上的翻译和 LLM 下拉框明确写出“默认 · 配置名”，同时仍可为这一次查询临时指定其他配置。

## 词卡来源与分栏

新保存词卡的 cards.json 中记录来源位置：漫画为页号和页图 URL，EPUB 为章节号。重新打开词卡后可点击来源跳转；漫画优先按页图 URL 定位，URL 不存在时才用保存的页号。跳转前位置进入阅读器的返回栈；阅读器底栏提供“返回第 N 页/章”。返回栈属于当前阅读会话，不改词卡文件。旧词卡没有来源时显示说明，不伪造页号。

词典、翻译和 LLM 分栏统一使用可点击标题与收起箭头。词典分栏标题显示当前词典名；没有匹配结果时自动收起。翻译与 LLM 的配置下拉框保持在标题行，收起后仍能看到所选配置。来源行显示页号、页图文件名或章节号。
