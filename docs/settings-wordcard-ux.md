## 词典导入任务（2026-10-26）

设置 → 词典 →「导入 Yomitan 词典…」选择一个或多个 ZIP 后立即入队，并自动展开右下角任务面板。每个 ZIP 独立显示检查、解压、解析、保存和加载索引阶段；有可靠总量时显示数据文件、词条或词典数量，没有总量时显示不定进度。设置页同时显示当前任务与「查看词典导入任务」，不依赖被“设置”文字覆盖的底部状态消息。

可以继续添加文件、离开设置阅读，或取消尚未开始的任务；正在解压／保存的任务不提供中途取消。活动与等待中的相同路径去重。某个 ZIP 失败不会阻断后续文件，完成结果包含已保存词条／词频数量、具体错误及跳过无效数据的提示。最近 20 项结果可清除，清除不卸载词典。

词典解析和索引运行在跨页面复用的 Worker，文件读写与解压不占书库全局锁。词典文件沿用现有格式及原子发布；索引加载失败时保留已安装文件与上一个可用索引，并提示在设置中「刷新索引」。导入期间暂禁启停、卸载与手动重建索引，避免同一部词典交错操作。

队列属于当前窗口会话：切换页面继续，刷新窗口／退出应用不会恢复等待项；已写入的词典保留，未发布的暂存文件下次启动清理。Worker 异常时任务明确标记中断，提示重启后先检查词典列表再重试。尚未实现跨重启续传。

## LLM 分析失败反馈（2026-10-23）

词卡分析失败时，把服务返回的 `error` 写入弹窗 `lastError` 并显示在 LLM 栏内；请求异常也有可重试提示。开始重试时清除旧错误，请求期间禁用重复分析，结束后恢复按钮。失败不写会话缓存或持久词卡，也不移除已有的成功结果。

此前 `useWordCards.analyzeWord` 在 `ok:false` 时提前返回，设置错误提示的代码只在成功分支执行，导致未配置模型、认证失败等结构化错误都表现为“点了没有反应”。本次同时发现运行实例的配置目录缺少 `llm.json`，仅恢复本机旧目录中已保存的该文件（目标不存在时创建、0600 权限、源文件保留）；没有新增自动迁移机制。配置和密钥不随代码提交。

## 设置的信息架构

设置页保留一列连续功能分组。全局工具栏左侧只有一个返回入口，按来源显示“返回书库／返回阅读／返回词汇与制卡”，页面右侧不再重复返回。设置内容标题和重置操作单独一行，分组导航和“查找设置分组”在下一行；导航跳转对应位置，搜索只匹配分组名，无结果时显示明确反馈。顺序为版本与更新、书库、词典、外观与布局、LLM 配置、翻译、词卡弹窗、OCR 与扩展、小说阅读器、漫画阅读器。界面/阅读偏好自动保存，LLM 配置与提示词仍须点击各自保存按钮，顶部说明区分两种行为。

词汇/制卡页同样取消内容区的第二个返回按钮。全局左上角与 Esc 共用按来源返回：从阅读进入时恢复同一本书和最新保存位置，从书库进入时返回书库。设置往返仍保留制卡页标签、步骤和表单。页面职责、操作层级和后续验收规则见 [UI/UX 原则](ui-ux-principles.md)。

OCR 扩展与仓库紧跟 OCR 默认引擎。OCR 单选项只决定全局预选引擎；漫画阅读器中的引擎下拉框可为本书选择其他已安装引擎，并记住本书覆盖值。多个引擎可以同时可用。

## LLM 与翻译配置

新建使用独立草稿，未保存时不进入已保存列表。LLM 新建在同一表单填写名称、地址、模型、温度和可选 API Key；本地模型可以留空 Key。点击一次“保存新配置”，主进程原子写入这套配置及 Key。修改已有 LLM 配置时，地址、模型、温度和 Key 的变更也统一由“保存”写入；“清除 Key”先标记待清除，保存后生效。主进程只返回 hasApiKey，不把明文回传。翻译新建填写名称、提供商和可选地址，保存后再补充密钥。配置名称以及翻译提供商在新建时确定，保存后只显示为固定信息；主进程也会保持已存身份不被后续覆盖式更新改写。

“词卡弹窗”卡片分成“翻译栏配置”和“LLM 分析栏配置”：前者只选择默认翻译引擎；后者选择默认 LLM 配置并编辑、保存分析提示词。LLM 与翻译配置卡片只管理可用配置。切换词卡默认配置不会清除未保存的新建草稿。删除已保存配置时，配置数组和默认 id 在同一次更新中提交。

翻译服务始终提供固定 id tr_bing_default 的 Bing 网页翻译项，首次打开就是默认项；它无需 Key、不能删除或改成其他提供商，设置中以简短的内置项显示。用户可以新建其他翻译配置，然后在“词卡弹窗”卡片中改设默认。弹窗里的引擎下拉框只列真实配置，当前默认项在名称后标“（默认）”；只有 Bing 时只出现 Bing 一项。单张词卡仍可临时改用其他配置。

## 阅读侧边栏

设置记住进入来源：从漫画/EPUB 打开后按钮显示“返回阅读”，退出时读取已保存位置恢复同一本书；从词汇/Anki 页打开后显示“返回词汇与制卡”，保留原标签、步骤与表单；书库来源返回书库。Esc 遵循相同返回规则。书库详情偏好默认开启，未选择时也保留空详情栏，避免首次选书改变列表宽度；手动关闭后仍按原偏好保存。

漫画和文本 EPUB 划词松手后仅显示鼠标旁的“查词”小按钮，保留选区；点击按钮才请求词典并打开词卡，普通点词仍直接查词。按钮可用 Esc、点击别处、滚动、换页/章或窗口缩放取消；异步返回时校验选区仍有效，取消后的旧查询不会再打开词卡。EPUB 章节内的 Esc 和滚动经桥接通知父窗口。

阅读器右上角为“沉浸 → 词卡夹”。漫画和文本 EPUB 的右栏都只展示词卡夹及数量，不再切换图层管理。批注通过页面内直接点击选中，操作条跟随当前笔迹/文字；底部及沉浸区保留共用快捷工具。画笔设置按需展开，橡皮擦作用于当前页全部可见且未锁定笔迹，翻页保留工具。具体手势、输入法及旧数据边界见 [批注交互](reader-annotations.md)。

## 词卡来源与分栏

新保存词卡的 cards.json 中记录来源位置：漫画为页号和页图 URL，EPUB 为章节号。重新打开词卡后可点击来源跳转；漫画优先按页图 URL 定位，URL 不存在时才用保存的页号。跳转前位置进入阅读器的返回栈；阅读器底栏提供“返回第 N 页/章”。返回栈属于当前阅读会话，不改词卡文件。旧词卡没有来源时显示说明，不伪造页号。

词典、翻译和 LLM 分栏统一使用可点击标题与收起箭头，相邻分栏只画一条边线。各栏展开状态作为应用级偏好写入 `localStorage` 的 `aralebook.settings.v1.wordCardSections`，跨词卡、书籍及重启沿用，各栏互不影响；同时打开的词卡也同步状态。旧设置缺字段时沿用原来的三栏展开默认值。没有匹配结果时词典栏临时收起，可手动展开查看提示，但不覆盖有词典结果时的展开偏好；后续命中仍按用户偏好显示。点击翻译按钮会展开翻译栏并记忆该状态。翻译与 LLM 的配置下拉框保持在标题行，收起后仍能看到所选配置。顶部词语与编辑图标同属一个按钮；来源行显示页号、页图文件名或章节号。

多词典命中时默认只显示查询排序中的第一部词典，该词典的各读音、词条及释义完整保留；“展开更多词典（另 N 部）”按词典分组展示全部结果，可再次收起。展开更多属于单张卡的临时状态，不写入偏好，新查词重新默认一部。仍可在分组中“采用此词典”指定词卡保存来源；收起更多或重新打开已保存词卡时优先显示所选词典，所选词典不再命中时回退到第一部。
