# 书签、摘录、读书笔记与阅读统计

核对日期：2026-10-15。当前实现基于 Tauri/Rust + React，共用漫画、图片小说和文本 EPUB 阅读入口。

## 使用入口

- 阅读器顶部提供“添加书签”“写笔记”“阅读记录”，沉浸工具条使用相同入口；EPUB 章节就绪前、漫画没有有效页时不能添加位置记录。
- 漫画有 OCR 文字层时及文本 EPUB 中，选中文字后出现“查词”和“摘录 / 笔记”。摘录直接保存用户所选原文，不调用词典、翻译或 LLM；可同时写笔记。
- 书库顶部“阅读记录与统计”查看全库。阅读器内默认当前书，可切换全部书籍。
- 阅读记录窗口分“书签、摘录与笔记”和“阅读与学习统计”两个标签。它独立于词卡夹，打开时暂停阅读计时，保留阅读器位置和工具上下文；底层翻页快捷键和原生翻页菜单在窗口打开时不执行。

## 记录、定位与导出

书签保存漫画页号／页图路径，或 EPUB 章节、章节相对路径及 UTF-16 字符偏移。同一个位置重复添加书签返回原记录。笔记可独立附在当前位置，摘录可附笔记；标题、笔记支持编辑，摘录原文在编辑界面只读。可以按类型和标题／原文／笔记／书名搜索。

“跳到原文”可跨书打开原书，再定位到页图或章节内位置；EPUB 摘录回跳时短暂高亮所选文字。跨章节等待桥接 ready 后恢复，不能只跳到章首。摘录列表保留原文，当前版本不在整本 EPUB 正文持续显示所有摘录高亮；漫画摘录回跳定位到页，不增加新的图像批注对象。

每次删除后提供最近一条的“撤销删除”，仅在本次窗口中保留撤销入口；继续删除会替换此入口，关闭窗口后不能从此入口恢复。删除书籍不会删除已经保存的阅读记录或历史统计，原书缺失的记录仍可搜索和导出，禁用回跳与编辑。当前撤销删除需要原书仍存在。

“复制 Markdown”与“导出 Markdown”作用于当前范围、类型和搜索匹配的全部记录。导出使用原生保存对话框，只写用户选择的位置，取消不写文件；临时文件完整写入并同步后原子替换，失败保留原文件。复制与文件导出均保留多行摘录、笔记、书名和位置。

位置不是跨版本通用锚点：页图路径或章节路径失效时拒绝跳转；章节内部 DOM 文本发生变化但路径相同时，旧偏移未必仍对应原文。目前没有云同步、富文本笔记、PDF 导出或独立复习调度。

## 统计口径

| 数据 | 口径 |
|---|---|
| 有效阅读时长 | 阅读器已有有效位置且无阅读记录窗口、文档可见并具有焦点；从最后一次鼠标／键盘／滚轮操作或 EPUB 点击／选区／滚动起最多计 2 分钟 |
| 暂停与恢复 | 失焦、隐藏、离开阅读器及打开阅读记录暂停；恢复交互不补记之前闲置时间；超过 60 秒的定时器间隔视为休眠／挂起，不补时长 |
| 漫画页／小说章节 | 当前可见页或章停留至少 2 秒后记录；快速翻过不记，双页可记录两页；统计周期内按书和位置去重，不表示已读完 |
| 查词次数 | 阅读器实际完成查词并打开弹窗才增加；重开已保存词卡不增加，AI 制卡的批量词典查询不增加 |
| 不同查询词 | 查询词做 NFKC 和首尾空白归一化后去重；不能据此判断掌握，也不承诺不同屈折形均归并为同一词 |
| 反复查询的词 | 周期内同一查询词出现至少两次，按次数展示前 20 个 |
| 周期 | 今天、最近 7 天、最近 30 天、全部时间，按机器本地日历日期分组；跨午夜的时长拆入两天 |

数据仅从本功能启用后开始积累，不从旧阅读位置或已有词卡推测历史时长。统计窗口按当前书／全库筛选，提供每日时长、页／章和查词表。

## 存储与代码

- `src/shared/reading.ts`：记录、统计、阅读器回调契约；`reading:*` 通过 `shared/ipc.ts` 和 `api-bridge.ts` 直接进入 Rust，不走词典／AI Worker。
- `src-tauri/src/reading.rs`：在既有后台互斥锁下读取、验证、更新 `<userData>/reading-journal.json` v1，沿用 `storage::write` 原子保存；包含 entries、按天按书汇总的 days 和最近 4096 个已确认上报 ID。
- 新建验证原书、范围、类型与长度；页图路径从原书取得，章节 href 由原书补入并核对。编辑／删除带 `updatedAt` 版本，冲突拒绝覆盖；时间戳单调递增。坏 JSON、未知版本与不符合存储结构的数据报错并保留文件。
- `src/core/reading/activity.ts`：前台／闲置时间区间、本地午夜拆分、跨日汇总和 Markdown 复制文本。
- `src/renderer/lib/reading-activity.ts`：10 秒计时与切页／失焦／离开时结算，串行上报；浏览器 `localStorage` 的 `aralebook.reading-outbox.v1` 只暂存未确认包，成功后删除。失败保留并重试，上报 ID 在 Rust 去重；已删除书籍的迟到包确认后丢弃，避免阻塞后续统计。
- `ReadingJournal.tsx`：原生 HTML dialog 提供焦点约束，显式保存、失败保留草稿、Esc 局部关闭。`ReaderView` 统一位置与入口，两个阅读器提供选区、实际位置和回跳；`useWordCards.openPopup` 记录阅读查词。

强退可能丢失最后一次尚未结算的约 10 秒；已进入暂存队列的包可以在下次打开阅读器或记录窗口时重试。去重只保证最近 4096 个上报 ID 的重放，不作为无限期事件账本。浏览器存储不可用时错误进入横幅，当前内存队列仍可上报，但不能保证刷新后的重试恢复。所有内容留在本机，不新增联网请求。
