# 页面结构与 UI/UX 原则

核对日期：2026-10-26。适用于当前 Tauri 桌面阅读、查词及制卡流程；后续界面改动应据此检查，不按历史截图恢复旧入口。

## macOS 原生沉浸悬停（2026-10-26）

simple fullscreen 在实际使用中仍出现“刚进入沉浸，文字与工具栏不响应悬停”。之前的手动成功只覆盖当时的隔离样本，不能证明稳定修复；窗口焦点、WebView first responder 和鼠标跟踪是不同状态，不能仅凭聚焦调用返回成功作判断。用户已选择接受独立全屏 Space。

macOS 改为调用 Tauri `set_fullscreen`，由系统管理全屏 Space、窗口尺寸、焦点、标题栏、菜单栏和 Dock。移除 simple fullscreen、手工样式修改、即时／延迟聚焦与递归 `updateTrackingAreas`。独立模块 `src-tauri/src/system/macos_fullscreen.rs` 通过 NSNotificationCenter 监听当前窗口的 Will/Did Enter/Exit FullScreen 通知，不替换 Tao 的窗口 delegate。以 Did 通知结束请求，期间不占用书库存储锁；状态区分过渡中、实际全屏和应用请求来源。系统绿按钮、快捷键或 Esc 退出会同步前端，应用主动返回书库则保留阅读偏好。请求超时及外部失败的 watchdog 只解除等待，不将定时器触发当成切换成功。

macOS 不再显示自定义系统栏开关，菜单栏和 Dock 使用原生全屏的边缘唤出方式；进入／退出按钮在过渡中禁用，避免重复操作。Windows／Linux 沉浸分支保持原逻辑。

双指缩放／Cmd、Ctrl＋滚轮现在根据 `deltaY` 的大小调整倍率，不再把每个微小事件都当成一次 20% 缩放。先统一像素／行／页增量，再使用指数倍率（每像素系数 0.0015），单次增量限制在 ±120 像素；零增量和非有限值忽略。100 次各 0.5 像素的放大总计约 7.8%，与一次 50 像素相同。按钮与键盘仍保留 20% 档位，逐页缩放记忆及上下限不变。

沉浸且倍率超过 100% 时，四边各增加对应视口尺寸 40% 的临时平移余量，便于把页边、页角或刘海遮挡处移到接近中央。普通滚动、双指滑动与既有空格拖动均沿用同一平移范围。余量不会持续回弹打断阅读；翻页、退出沉浸或调整窗口范围时清除，缩回适配倍率也回到正常边界。工作视图与持久位置分开，保存时按正常边界夹紧，避免重新打开页面后停在大片空白处。

## 漫画文字光标方向（2026-10-23）

OCR 命中块按 `TextBlock.vertical` 显式选择光标：竖排使用 `cursor: vertical-text`，横排使用 `cursor: text`。此前 CSS 将所有命中块固定为 `text`，即使设置了竖排 `writing-mode`，macOS 上也可能仍显示普通文字光标。这里仅调整光标，不改变点词、拖选或原图坐标计算。

macOS 提供 [NSCursor.iBeamCursorForVerticalLayout](https://developer.apple.com/documentation/appkit/nscursor/ibeamcursorforverticallayout)，[WebKit 的 macOS 实现](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/platform/mac/CursorMac.mm)将 `VerticalText` 映射到这个系统光标，因此不需要自绘光标或修改系统设置。

2026-10-23 / macOS arm64 / Node 22.22.2：`npm run typecheck`、`npm run build:renderer` 通过；内置浏览器加载真实 `ComicTextLayer` 组件，最终计算样式分别为 `vertical-rl / vertical-text` 与 `horizontal-tb / text`。未目视验收独立 Tauri 原生窗口的系统指针，也未在 Windows 重测；普通浏览器截图不作为系统指针外观证明。

## 页面职责与导航

| 页面/区域 | 主要任务 | 返回/辅助操作 |
|---|---|---|
| 书库 | 导入、筛选、选择并打开书籍 | 左侧筛选、右侧详情按用户偏好展开；无选择时可保留详情占位 |
| 阅读器 | 阅读、查词、保存词卡、直接批注 | 左上角返回书库；右上角沉浸、词卡夹；底部阅读/排版/OCR 与批注工具 |
| 词汇与制卡 | 词汇查看和五步制卡 | 左上角按来源返回阅读或书库；词汇/制卡是页内标签，制卡步骤是流程导航 |
| 设置 | 应用偏好、词典、模型及服务配置 | 左上角返回进入来源；页内导航只定位设置分组，不承担返回职责 |
| 词卡夹 | 搜索、查看、打开已保存词卡 | 阅读器右侧专用面板，收起不退出阅读，不切换批注管理 |
| 阅读记录窗口 | 当前书／全库的书签、摘录、笔记与按天统计 | 独立 dialog，不占词卡侧栏；Esc 先关闭窗口，未保存修改确认后放弃；打开时暂停计时 |
| 批注操作条 | 编辑当前选中的笔迹/文字 | 在页面直接点选；靠近内容显示样式、编辑及删除；草稿提供完成/取消 |
| 任务入口 | 查看 OCR/制卡后台进度 | 切换页面不中断任务；返回按钮不等于取消任务 |

设置可从书库、阅读器、词汇/制卡页进入，并返回同一来源。制卡页从阅读器进入时返回同一本书的最新已保存位置；从书库进入时返回书库。设置覆盖制卡页期间保留原标签、步骤和表单。词卡来源跳转属于阅读器内部历史，使用明确的“返回第 N 页/章”，不与全局页面返回混用。

## 交互原则

1. **一个层级，一个返回入口。** 页面返回统一在全局工具栏左侧，名字写明目的地。内容区不重复另放一个作用相同或目的地不同的返回。Esc 与可见返回遵循同一来源规则。
2. **先操作内容，再考虑结构。** 批注直接点选、移动、编辑、删除；存储图层不成为开始画笔、擦除或输入文字的前提。侧栏只承载用户需要持续浏览的词卡。
3. **工具与退出分工明确。** 画笔/橡皮/文字表示当前模式，选中状态可见；再次点当前编辑工具返回阅读，切工具先提交草稿。翻页提交当前内容并保留工具；返回阅读、退出沉浸、显示系统栏是各自独立的操作。
4. **参数靠近对象，按需展开。** 画笔颜色/粗细在画笔菜单内；选中文字或笔迹才显示其样式和删除操作。浮动条跟随对象但限制在窗口内，不能因页面缩小被容器裁掉。
5. **低风险操作可逆。** 文字新建取消不留空内容，草稿样式随草稿一起完成或取消；直接删除可以撤销。全书删除、重置、放弃未保存修改等须说明范围并确认。不要用确认框打断每次绘画或文字提交。
6. **Esc 从局部逐级退出。** 打开的参数菜单先收起；文字草稿先取消；已选对象先取消选择；再退出批注工具，最后返回来源页。输入法组合输入时不执行提交、删除或页面返回。
7. **保留工作上下文。** 设置往返恢复阅读位置，保留制卡草稿；侧栏展开不切工具，不取消批注。原生窗口/系统栏变化不应改变文字草稿或突然重排阅读内容。
8. **保存状态和失败可理解。** 区分自动保存与需按保存的服务表单。批注显示加载/保存中/已保存/错误；失败保留本地内容并给出重试。原图失配、版本冲突、空状态和搜索无结果都要明确说明原因。
9. **同一动作，各处一致。** 普通和沉浸工具共用实现、状态与禁用条件；橡皮擦依据当前页可编辑笔迹决定可用，不要求猜测隐藏的图层选择。禁用需有可理解的提示。
10. **可用键盘，也看得清。** 图标有可读名称、选中状态和焦点；页面批注可用 Tab/Enter 选择，工具菜单可用 Esc 退出。保留原生 textarea 处理光标、选区、换行和中日输入法，字号/颜色设置有标签，不能只靠颜色表示状态。

## 漫画视图记忆（2026-10-19）

漫画／图片小说的每页分别记忆缩放倍率与画面平移位置。翻到未调整的页时使用当前适配方式的 100% 并居中；翻回已调整页时直接读取该页记录，避免先显示上一页倍率再切换的闪动。100% 仍指适配倍率，只有“原始尺寸”模式对应原图像素。

记录按书保存在本机 localStorage（`aralebook.comic-page-views.v1:<bookId>`），调整后延迟 250ms 写入，离开阅读器或 pagehide 时补写。重新打开书或刷新可恢复；存储不可用时保留当前阅读器会话中的记录。该数据不参与服务器阅读进度同步。只记录调整过的视图；原图 URL 或尺寸变化后使用默认视图。存储中损坏的条目跳过，不影响其余页面。

双页按当前可见的跨页组合记忆，左右阅读方向分别记忆；单页与跨页、不同适配模式互不覆盖（双页模式中仍单独显示的页可复用相同单页记录）。切回原来的组合／适配方式会恢复该视图。窗口、沉浸模式或侧栏引起尺寸变化时，画面位置夹在可达范围内，不覆盖存储中的原位置；用户继续调整时以当前可见位置为起点。重置按钮、数字 0 和菜单重置统一清掉当前视图的倍率与位置，恢复默认适配并居中，其他页不变。
